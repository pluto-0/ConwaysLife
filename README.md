# Conway's Game of Life

This is a simple implementation of Conway's Game of Life I put together a few months ago while learning javascript.  Simply unzip and load index.html into your browser to use.  The user can click on any tile they wish to swap the state from off to on or vice versa.  Then they can click play to watch the board change in real time or go forward/backward by 1 step using the arrows.  I had planed to implement a way to save certain states or paste patterns onto the board, but the project was mostly educational and I thought it had served its purpose.
